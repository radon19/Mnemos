# Knowledge globe

`knowledge-globe.svg` is a local orthographic projection of Natural Earth's
1:110m country polygons, centered at 12°E / 18°N. It is decorative and does
not represent Mnemos users, adoption or transactions.

Data: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson

Natural Earth data is public domain:
https://www.naturalearthdata.com/about/terms-of-use/
